# Варовик — концепция на 13:33

Концептуален сайт за **измислена** жилищна сграда — за портфолиото на 13:33 Digital Studio. Няма инвеститор, цени или срокове; всичко е обозначено като концепция.

**Идеята:** скролът ви разхожда. Тръгвате от басейна пред сградата в синия час, минавате по алеята, влизате през травертиновия портал, през лобито — и излизате във вътрешния двор. Филмът е разрязан на кадри и се рисува на canvas според скрола (с плавен преход между съседни кадри), а текстовете, точките в лобито и линията вдясно следват позицията.

Кадрите, видеото и снимките са генерирани с Higgsfield (GPT Image 2.5 за ключовите кадри, MiniMax H3 за преходите между тях). Изходните файлове не са в репото — само готовите за уеб WebP.

React + TypeScript + Vite, Tailwind CSS v4, GSAP ScrollTrigger + Lenis.

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # tsc + production build в dist/
npm run preview
```

## Медия

```bash
python3 scripts/build_frames.py seg1.mp4 seg2.mp4 seg3.mp4   # → public/frames (десктоп + телефонен изрез) и manifest.json
python3 scripts/build_stills.py <папка с PNG>                 # → public/media (материали, жилища, вечер)
```

Кадрите се зареждат прогресивно: първо спирките и всеки 8-и, после останалите. На телефон се ползва централен изрез (`m/`), на десктоп — пълният кадър (`d/`).

## Структура

| Път | Какво е |
| --- | --- |
| `src/components/arrival.tsx` | Скрол-филмът: canvas, графикът със спирките, главите, точките в лобито, линията вдясно |
| `src/components/residences.tsx` | Трите вида жилища: снимка + план, който се рисува сам |
| `src/components/evening.tsx` | Сградата вечер — пълноекранна пауза |
| `src/components/materials.tsx` | Хоризонтална лента с материалите (десктоп), списък на телефон |
| `src/components/inquiry.tsx` | Демо форма за оглед — не изпраща данни |
| `src/data/content.ts` | Всички текстове и прозорците на главите във филма |

## Правила

- Всичко видимо е на български; `<html lang="bg">` включва българските форми на Cormorant и Manrope.
- Един акцент (месинг) — само за главното действие и текущото състояние.
- `prefers-reduced-motion`: без плавен скрол и без инерция на филма.
