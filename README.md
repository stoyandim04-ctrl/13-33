# 13:33 — Digital Studio

## Няколко сайта в едно хранилище

Сайтът на студиото остава в корена (`src/` → `dist/`). Клиентските приложения се държат отделно в `apps/`, със собствени входни файлове, дизайн и build outputs.

| Сайт | Development | Build | Output |
| --- | --- | --- | --- |
| 13:33 Studio | `npm run dev` | `npm run build` | `dist` |
| Strong Muse — прототип | `npm run dev:strong-muse` | `npm run build:strong-muse` | `apps/strong-muse/dist` |

`npm run build:all` проверява двата сайта. Всеки може да бъде свързан с отделен hosting project и домейн, като installation directory е коренът на repository, а build/output настройките са тези от таблицата. Нищо ново не е публикувано.

Общите проектни файлове за Codex и Claude Code са в `docs/strong-muse`; виж и [инструкциите за приложението](apps/strong-muse/README.md).

Сайтът на 13:33: React + TypeScript + Tailwind CSS v4 (shadcn-съвместима структура), Three.js и GSAP.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка на TypeScript + production build в dist/
npm run preview    # преглед на production build
npm run typecheck
npm run media      # прерисува постерите/видеата на концептуалните проекти
```

## Какво е адаптирано спрямо оригиналните компоненти

**Horizon** — запазени: звездите, мъглявината, четирите релефа, атмосферата, bloom, плавната камера, интрото с разделени символи. Променени: цветовете (синьо #5B7CFA, ледено #A8D8FF, графитени силуети); един hero и един преход вместо HORIZON/COSMOS/INFINITY; локален прогрес на секцията (ScrollTrigger, вързан към hero-то); отделни refs за всеки текст; пълно освобождаване на ресурсите; по-лека сцена на телефон (по-малко звезди, по-слаб bloom, по-нисък pixel ratio, разширен FOV за портретен екран); статичен хоризонт без WebGL; неподвижен кадър при reduced motion; three.js се зарежда асинхронно.

**WorksWheel** — запазени: геометрията, пръстенът, който се отваря в перспективна спирала, един rAF проход, easing, culling, индексът. Променено: колелото следва скрола на собствената си секция (sticky сцена) вместо да прихваща `wheel` събития — hero-то и колелото имат отделни участъци от страницата и не се борят за един жест; touch скролът е естествен; след последния проект страницата продължава. `WHEEL_UNITS = 550` px скрол на проект, `DRAG_UNITS = 320` px дърпане/плъзгане на проект. Колелото се установява в посоката на движение (12% стигат), така че и единичен нотч сменя проекта. Добавени: постер + видео (само предният прозорец зарежда и пуска видео), клик/Enter отваря проекта, страничен прозорец или индекс го избира, дърпане не отваря линк, клавиатура (↑ ↓ Home End).

## Материали за замяна

1. **Проекти.** Всички 6 в портфолиото са **концепции на 13:33** (означени „Концепция“ навсякъде). Медията им е рендерирана от собствени мокъпи (`scripts/concept-mocks.mjs`) — без stock и без чужди сайтове. За реален проект: добави запис в `src/data/projects.ts` със `status` (`live`, `in-progress`, `prototype`, `own-product`) и сложи в `public/projects/<slug>/`:
   - `poster.webp` — 1450×1000 (съотношение 1.45);
   - `preview.mp4` (H.264) и `preview.webm` (VP9) — 6–10 s, без звук. Настройките на ffmpeg са в `scripts/build-concept-media.mjs`;
   - `liveUrl` — само ако сайтът е публичен и клиентът е съгласен.
   Кандидатите от Notion (VELION LAB, INTNS / FitCheck, Strong Muse) не са добавени, докато нямат потвърден линк, запис, статус и разрешение.
2. **Имейл за контакт** — `VITE_CONTACT_EMAIL` (бизнес имейлът още не е решен).
3. **Текстове за потвърждение** — обещанията в контактната секция („Четем всяко запитване лично“, „Първият разговор е … без ангажимент“) и бюджетните диапазони във формата.
4. **Лого** — засега знакът е типографският „13:33“; favicon-ът е временен.

## Интеграции, които изискват настройка

Копирай `.env.example` в `.env.local`. Всичко с префикс `VITE_` отива в браузъра — **никога не слагай ключове там**.

- **Изпращане на запитвания** — `VITE_INQUIRY_ENDPOINT`: POST, JSON (`Inquiry` от `src/lib/brief.ts`). Без него нищо не се изпраща и формата казва това честно, с възможност да копираш данните (и да ги пратиш по имейл, ако е зададен `VITE_CONTACT_EMAIL`). Успех се показва само при отговор 2xx.
- **AI Project Brief** — `VITE_AI_BRIEF_ENDPOINT`: сървърен route, който пази ключа на AI доставчика и връща `AiBriefResponse` (договорът е в `src/lib/brief.ts`). Без него се показва само структурираният въпросник — без симулирани AI отговори.
- **Хостинг** — SPA; `vercel.json` пренасочва маршрутите към `index.html`. Нищо не е публикувано.
