# Варовик — концепция на 13:33

Концептуален сайт за **измислена** жилищна сграда — за портфолиото на 13:33 Digital Studio. Няма инвеститор, цени или срокове; всичко в сайта е обозначено като концепция.

**Идеята:** скролът е един ден. Докато слизате надолу, слънцето минава над сградата от 06:30 до 20:40 — сенките се движат по терасите, залезът се оглежда в басейна, а вечерта прозорците светват. Часовникът в ъгъла показва колко е часът в сцената.

React + TypeScript + Vite, Tailwind CSS v4, Three.js, GSAP ScrollTrigger + Lenis.

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # tsc + production build в dist/
npm run preview
```

`?quality=lite` / `?quality=hq` насилва качеството на 3D сцената (по подразбиране — lite на телефони и слаби машини).

## Структура

| Път | Какво е |
| --- | --- |
| `src/scene/varovik-scene.ts` | Сцената: сграда, терен, маслини, басейн-огледало, небе, слънце; всичко от примитиви, без модели и снимки |
| `src/scene/day.ts` | Общият часовник: прогрес на скрола → час → нощ; ползват го и сцената, и текстът |
| `src/components/day-story.tsx` | Закованата 3D секция с главите, часовника и линията на деня |
| `src/components/residences.tsx` | Трите вида жилища с плановете, които се рисуват сами |
| `src/components/materials.tsx` | Хоризонтална лента с материалите (десктоп), списък на телефон |
| `src/lib/textures.ts` | Травертин, дъб и лен, нарисувани на canvas |
| `src/data/content.ts` | Всички текстове |

## Правила

- Всичко видимо е на български; `<html lang="bg">` включва българските форми на Cormorant и Manrope.
- Един акцент (теракота `#B05D38`) — само за главното действие и текущото състояние.
- Формата за запитване е демонстрация и не изпраща данни.
- `prefers-reduced-motion`: без плавен скрол, без интро и дрейф на камерата.
