# Notes for agents working on this repo

- Bulgarian first, English second. Structured copy lives twice in `src/data/content.ts` (`useContent()`); every other visible string is written in Bulgarian in the component and wrapped in `tr()` from `src/lib/i18n.tsx`, with its English in `src/lib/en.ts` (the Bulgarian text is the key — a missing key shows Bulgarian). The switch is in the header; the choice is kept in localStorage and sets `<html lang>`. Manrope carries the Bulgarian Cyrillic forms — only switch to fonts with `cyrl/BGR` locl forms. The studio panel (`/studio`) stays Bulgarian.
- Never invent clients, results or testimonials. Concept projects stay labelled (`status: "concept"`). The one time promise is the studio's own: the first version reaches the client's inbox within 4 working days of the deposit (`FIRST_VERSION_DAYS`). The word „основател“/founder never appears on the public site; we speak as the team.
- Visual system lives in `src/index.css` (`@theme`): minimal and luxurious — warm ivory paper (#F4F1EC, two close shades), ink (#121110) for text and the one action colour, stone (#6E6A63) for quiet text, ink hairlines at 12%. No gradients, no glow, no second colour. Fixed type scale (`text-label/body/lead/title/heading/display`); statements are Manrope 300, very large; every section opens with `eyebrow → heading → lead`.
- The primary action is always the `RainbowLink`/`RainbowButton` (`components/ui/rainbow-button.tsx`, now an ink pill), one per view; other buttons lift and glow on hover (`components/ui/button.tsx`), menu links use `.nav-link`.
- Home: hero (`grid-hero.tsx`, type only: „Дигитални услуги / на следващо ниво.“, the promise, the ink button) → Manifest → WorksWheel → Services → Process (pinned, the four steps take turns) → Contact. The wheel shows no visible words (only the cards, the „Концепция“ badges and the arrows on phones); its last card is a frosted-glass folder („Твоят проект“) with our frames inside that leads to `/zapochni` — new projects go in front of it. No "why us" paragraphs, no FAQ: the chat answers questions. A project in the wheel links straight to its live site (new tab) — no project pages.
- `components/ui/works-wheel.tsx` is adapted from a provided original (see README); `components/ui/horizon-*` is the retired 3D hero, kept unused. Keep the wheel's behaviour; the hero and the wheel own separate stretches of the page scroll. The wheel takes over wheel/touch gestures only while its stage is pinned (one gesture = one project) and hands them back above the ring and after the last project — don't capture gestures anywhere else.
- No secrets in client code: only `VITE_*` public values. Inquiries/AI/payments go through the server routes in `api/` (Supabase service key, Anthropic key, Stripe and Resend keys live only there). The AI consultant prices the project itself, item by item, inside `PRICE_GUIDE` (`src/lib/inquiry-shared.ts`, kept low on purpose); the server checks the total and sets the deposit to `DEPOSIT_SHARE` of it (15%, rounded to 5 €). Without a computed price the deposit falls back to `DEPOSITS` by project type (0 = no payment step). The price and deposit are shown on the client's page and paid there through Stripe. Every client message in the chat is forwarded to the studio's Telegram. No chat between client and studio after that: the team writes by e-mail.
- Before finishing: `npm run build` (runs `tsc -b`).
