# Strong Muse — rules for every coding agent

- Read `../../docs/strong-muse/brief.md`, `decisions.md`, `backlog.md`, and `handoff.md` first. They are the shared source for Codex and Claude Code.
- This application is a review prototype. The client's final design, site goal and commercial model are not approved. Keep `noindex` and the concept notice until approved for release.
- Preserve the exact confirmed slogans and program names. Planned programs must not have purchase buttons, prices, availability claims, countdowns or invented outcomes.
- Do not copy FITQUEEN photography, products or branding. Current artwork is an original graphical placeholder, not a portrait of Anna. Actual photos and PDFs are not supplied in the export.
- Never invent biography, credentials, awards, testimonials or contact information. Nutrition documents need the review recorded in the brief before public offering; do not expose downloadable PDFs now.
- The local visual tokens belong to this application. Do not apply its styles, metadata, routes or identity to the root studio site.
- Use Jev only for narrow structured semantic judgments (Noul, Choice, Score) with real, source-labeled requirements. Use normal code for deterministic rules. Jev cannot establish client approval, product availability or permission. Read the official TypeSafe skill and current docs before changing API calls.
- `TYPESAFE_API_KEY` is a cloud Network secret scoped to `api.typesafe.ai`. Never log/store its value, prefix it with `VITE_`, or call Jev from this browser application. Prior evaluation artifacts are in `docs/strong-muse/jev-evaluation.json`, without credentials. No production Jev client has been approved or added here.
- From the repository root: `npm run build:all`, then `npm run test:strong-muse`. The browser test uses `CHROMIUM_PATH` if provided, otherwise system Chromium or Playwright's installed browser. No live Jev calls are made by tests.
- Preserve studio behavior. No live deployment without explicit approval. Update handoff and decisions after material changes.
