# ЗВЯР — концепция за енергийна напитка

Концептуален проект на 13:33. Марката, вкусовете, съставът и цените са измислени; нищо не се продава. Вдъхновено от анимираните сайтове за напитки (кенче, което води през страницата), но по-грубо: цял екран в цвета на вкуса, черни рамки, твърди сенки, ленти като предупредителни.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc -b + vite build → dist/
```

## Какво има на страницата

1. **Интро** (`components/intro.tsx`) — ЗВЯР се забива буква по буква, броячът стига 100, когато 3D сцената е готова, екранът се разцепва и кенчетата падат с отскок.
2. **Hero** (`components/hero.tsx`) — шестте кенчета във ветрило, следят курсора; вкусът се сменя сам на 4 s, докато човек не избере (цветни бутони, ← →). Смяната: диагонален удар в акцентния цвят, трус на камерата, новият цвят на целия сайт.
3. **Вътре** (`components/tour.tsx`) — избраното кенче отива вдясно и се завърта с един пълен оборот при скрол (вижда се гърбът: хранителна таблица и предупреждение); отляво минават четирите числа.
4. **Дръж се / Пуснат** (`components/burst.tsx`) — кенчето трепери все по-силно, на 30% от секцията бяла светкавица и експлозия: резенчета/плодове според вкуса, лед и капки летят към екрана; две кръстосани ленти.
5. **Линията** (`components/lineup.tsx`) — кремав фон, шестте кенчета в редица (3×2 на телефон); посоченото подскача и се върти, клик → магазина с този вкус.
6. **Магазин** (`components/shop.tsx`) — кенчето и две копия зад него, дърпа се за завъртане; вкус, кашон 4/12/24, брой, количка (`localStorage`). „Към плащане“ казва честно, че е концепция.
7. **Въпроси**, **футър** — с предупреждението за кофеина.

## 3D

- `lib/can.ts` — кенчето е истинска геометрия (цилиндър + струговани профили + капак + халка); етикетът се рисува в `<canvas>` за всеки вкус (лице: ЗВЯР вертикално и името; гръб: таблица, предупреждение, съставки). Без външни модели и снимки.
- `lib/stage.ts` — едно платно за цялата страница. Секциите слагат котви в DOM (`data-anchor`), кенчето отива там, където е котвата, с височината ѝ; между секциите позата се смесва според това колко от следващата (`data-stage`) е влязла в екрана. Пружина върху всяка стойност дава отскока.
- На телефон: по-малко частици, лед без transmission, по-нисък pixel ratio. При `prefers-reduced-motion` няма трус и треперене.
- `?shot` в адреса позволява голяма стъпка на пружината — само за снимки в бавен (софтуерен) браузър.

## Данни

`src/data/flavours.ts` — вкусове, цветове, числата, кашоните и цените (€), въпросите. Кофеинът е 32 мг/100 мл (160 мг в 500 мл), затова кенчето и футърът носят задължителното предупреждение.
