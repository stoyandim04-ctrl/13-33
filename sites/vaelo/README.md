# VAELO — концепция за премиум марка дрехи

Концептуален проект на 13:33. Брандът, дрехите, цените и адресът са измислени; снимките и 360° завъртанията са генерирани с Higgsfield (GPT Image 2.5 → Seedance 2.5 → video background remover).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc -b + vite build → dist/
```

## Какво има на страницата

1. **Орбита** (`components/orbit.tsx`) — осемте дрехи влитат от разпилени точки и обикалят в перспективна елипса около думата VAELO: отпред минават пред нея, отзад — зад нея, по-малки и размазани. Върти се сама; дърпане (мишка/пръст) я завърта и я довърта до най-близката дреха; точките и ← → избират; клик върху предната отваря визьора.
2. **Гардеробът** (`components/rail.tsx`) — дрехите висят на релса в профил. Посочена дреха се обръща с лице (истински кадри от завъртането), съседните се отдръпват. На телефон релсата се плъзга хоризонтално.
3. **Колекцията** (`components/collection.tsx`) — мрежа; картата се накланя след курсора, а дрехата се обръща с гръб.
4. **Ателието** — изречение, чиито думи светват при скрол, и три правила.
5. **Визьорът** (`components/viewer.tsx`) — цял екран: дрехата се върти след курсора (лява/дясна половина = накъде), Лице/Профил/Гръб, размери, количка. Esc, ← →.
6. **Количката** — пази се в `localStorage`. „Към плащане“ казва честно, че това е концепция.

## Данни и медия

- `src/data/products.ts` — дрехите, цените (€), материи, кройка.
- `public/img/p/<slug>.webp` — 900×1200, прозрачен фон, лице.
- `public/img/spin/<slug>/00–47.webp` — един пълен оборот, прозрачен фон; 00 = лице, 24 = гръб. Прозрачността е изчислена от оригиналното видео (сив фон) и изрязаното (на черно): `alpha = 1 − (оригинал − изрязано) / фон`.
- Кадрите се рисуват в `<canvas>` (`lib/spin.ts`), за да е смяната мигновена; зареждат се, когато секцията наближи.

## Честност

Няма плащане и нищо не се поръчва; бюлетинът не изпраща нищо. Футърът казва, че всичко е концепция.
