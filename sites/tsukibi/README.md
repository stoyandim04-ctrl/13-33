# Цукиби 月火 — концепция за азиатски ресторант

Концептуален проект на 13:33. Ресторантът, логото, менюто, цените и адресът са измислени; снимките на ястията и интериора са генерирани с Higgsfield (как са изрязани чиниите — виж „Данни“).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc -b + vite build → dist/
```

## Страници

- `/` — интро с изчертаване на логото; hero „луна“ — огънят се вижда през кръгъл прозорец, който при скрол се разширява до цял екран; искри (canvas); философия (думите светват при скрол); „Една вечер в Цукиби“; галерия „Пространството“; „Огънят“ с паралакс и броячи; омакасе — интериорът се разкрива през „луна“ (clip-path); бар; резервация; футър. Ястията са само в менюто.
- `/menu` (`/menu?dish=sashimi`) — пет категории (Салати, Предястия, Робата, Риби, Суши) по 4 ястия. Един жест на колелото/тракпада = едно ястие (инерцията не прескача), също стрелки и плъзгане. Натискане на чинията я накланя в 3D и над съставките се изправят табелки (`components/plate-pins.tsx`). Само разглеждане — без поръчки.

## Данни

- `src/data/menu.ts` — ястията, цените и точките на съставките (`hotspots`, в % от квадрата на изображението).
- `public/img/dishes/*.webp` — 900×900, прозрачен фон: кръгът на чинията + стърчащите части (нори, шишове) от Higgsfield background remover.
- `public/img/scenes/` — атмосфера и видеото на робатата (mp4 + webm).

## Честност

Няма поръчки. Формата за резервация не изпраща нищо — интерфейсът казва това. Футърът отбелязва, че всичко е концепция.
