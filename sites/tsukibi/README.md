# Цукиби 月火 — концепция за азиатски ресторант

Концептуален проект на 13:33. Ресторантът, логото, менюто, цените и адресът са измислени; снимките на ястията и интериора са генерирани с Higgsfield (как са изрязани чиниите — виж „Данни“).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc -b + vite build → dist/
```

## Страници

- `/` — интро с изчертаване на логото; hero с видео на робатата, искри (canvas) и чиния, която изплува и се върти при скрол; философия (думите светват при скрол); пет подписни чинии в хоризонтален скрол; „Огънят“ с паралакс и броячи; омакасе — интериорът се разкрива през „луна“ (clip-path); бар; резервация; футър.
- `/menu` (`/menu?dish=ramen`) — чиния по чиния: скрол/стрелки/плъзгане сменят ястието (чинията се завърта навън и следващата влиза), при посочване се изчертават надписи към съставките, списък с всички ястия, категории, поръчка с летяща чиния към количката.

## Данни

- `src/data/menu.ts` — ястията, цените и точките на съставките (`hotspots`, в % от квадрата на изображението).
- `public/img/dishes/*.webp` — 900×900, прозрачен фон: кръгът на чинията + стърчащите части (нори, шишове) от Higgsfield background remover.
- `public/img/scenes/` — атмосфера и видеото на робатата (mp4 + webm).

## Честност

Резервацията и поръчката не изпращат нищо — интерфейсът казва това. Футърът отбелязва, че всичко е концепция.
